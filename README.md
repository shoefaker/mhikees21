# Mhikee · Twenty One

Updated GitHub Pages files for Mhikee’s birthday site. This version points the birthday video player to the higher-quality Google Drive upload.

## Update your existing GitHub Pages site

1. Extract this ZIP.
2. Open your repository (`shoefaker/mhikees21`) and choose **Add file → Upload files**.
3. Upload the extracted `app.js` file and the whole `assets` folder. Keep `app.js` at the repository top level and `assets` as a folder beside it. When prompted, commit the changes. These replace the existing `app.js` and add/replace the website assets.
4. Confirm the repository shows `assets/cat.jpg`, `assets/hogwarts.jpg`, `assets/romcom.jpg`, and `assets/vegas.jpg` inside the `assets` folder.
5. After GitHub Pages finishes publishing, refresh the site. The video button now uses the new Google Drive video.

The video is embedded from Google Drive and is not stored in this ZIP. For visitors to watch without signing in, its Drive sharing setting must be **Anyone with the link → Viewer**.

If the video will not load in the embedded player, open it directly in Drive to confirm it has finished processing and that the sharing setting works in a private browser window.
